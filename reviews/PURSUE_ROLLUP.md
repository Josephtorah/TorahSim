## Cross-cutting (do these regardless of folder)

1. **Separate fact / interpretation / intent** on every claim.  
2. **Mark prose-only** — never promote unreproducible stats. (Default audits: English docs only; no re-run unless asked.)  
3. **Nulls & comparatives** — shuffle, Prophets, other legal corpora before “Torah-only architecture.”  
4. **Prefer native structure** — layers, פ/ס blocks, cantillation trees — over imposed OS stories.  
5. **Legal/ritual signal** — Leviticus-type material and formulaic tables (e.g. Num 7) keep showing up.  
6. **Generated “programs” that only trace-narrate are not proof of semantics** (v3 quantification).  
7. **Distrust entropy/Fibonacci/compression “signals” without proper baselines** (v3 dead ends).  
8. **Kill bad channels with real stats** (v4 gematria null as model).  
9. **Coverage ≠ accuracy** — 100% classification via special cases is overfitting (v4).  
10. **Maintain a rejected-signal catalog** — grammar is not opcode (v5, v6 CLEAN filter).  
11. **Prose vs poetic te'amim** — hard fork for any Tanakh-wide parser (v5, v6); Job prose exception easy to miss.  
12. **Tag [TORAH] vs [PARSER]** and log assumptions (v5; v6 ASSUMPTIONS.md pattern).  
13. **Suspect our reading before the text** when conditionals “die” (v6 כי lesson).  
14. **“Oracle” without a runner is not a test suite** (v6: 686 Mishnah pairs write-only).  
15. **Do not import whole-corpus counters** into a partial project — fire/dead stats lie when sliced (v6 Q20).  
16. **Verify Oral claims against corpus Hebrew quotes** — strip niqqud, search broadly, quote the line (v7 PARSE_RULES_VERIFIED method).  
17. **Provenance tiers:** verified-from-source / observation / implementation — never mix (v7).  
18. **Retire when imposed logic accumulates** — “no add/diminish” as process, not only slogan (v7 self-retire).  
19. **כי is multi-sense in Oral** — do not freeze a single BECAUSE-only rule without context (v7 verification catch; tension with v6 first-token rule).  
20. **#IMPOSED brand** — label every external aid; silent outside structure was repeatedly wrong (v7.5).  
21. **Text-only roots plateau** — ~37% in their trial; morphology tables OK if provenance-tagged (v7.5).  
22. **Codegen-from-trees as derivation = contamination** (v5 lesson restated v7.5) — Pre-Code YAML stays canonical here.  
23. **Rules must not over-fire** — local to source evidence first; expand only with proof (v8).  
24. **Morph form is signal** — don’t collapse to root-only too early (v8 Lev 13 anecdote).  
25. **“Listening problem, not programming problem”** — read tree/text before inventing machinery (v8 meta).  
26. **Type at word level, bottom-up** — leaf-level typing causes homonym/pronoun failures (Genesis-Experiment ← v8 review).  
27. **OSHB + lemma identity** with provenance — better than heuristic affix stripping (Genesis-Experiment).  
28. **3-verse window (declare/evaluate/execute)** — candidate for narrative; not default for casuistic law (Genesis-Experiment).  
29. **Genre matters** — narrative (e.g. Nehemiah) can be typed sequential data with no IF/THEN; that does not kill legal logic (PureV9).  
30. **Look for conditionals in diagnostic law (Lev 13–14), not narrative compilers** (PureV9 pivot).  
31. **“Formal types ≠ imperative code”** — don’t oversell trees as Python (PureV9 experiments).  
32. **Search engine ≠ compiler** — finding sugya segments ≠ emitting verse logic (Cantillation-Paradox honesty).  
33. **Sliding window (text+tree → plain rule → optional code)** is a good human method; code still not the derivation home (Cantillation-Paradox).
