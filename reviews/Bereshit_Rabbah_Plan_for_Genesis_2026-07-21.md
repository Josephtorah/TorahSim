## 2. Gates (access controls / opening rules)

A **gate** is a rule about **who may open what, how far, and in which direction**.

Not Sefer Yetzirah’s letter-pair “gates” unless added later as dual-track comparative.

| Gate | What it does | Where seen |
|------|----------------|------------|
| **Query-bound** | Deny “what is above / below / before / after” creation | BR 1:10 (Bet); Chagigah |
| **Cohort** | Don’t expound Ma’aseh Bereshit to a full class | Mishnah Chagigah 2:1 |
| **Honor** | Don’t use creation-study as self-glorification | BR 1:5 |
| **Speech** | Careful naming of substrate (tohu/bohu) | BR 1:5 |
| **Root** | No co-creator angels on day 1; singular create | BR 1:3, 1:7 |
| **Name-order** | How Divine Name is ordered in speech/dedication | BR 1:12–13 |
| **Entry glyph** | World “opens” with **Bet**, not Alef-first dump | BR 1:10 |

**Developer gloss:**

```text
if query.direction in {above, below, before, after}: deny
if cohort_size > allowed: deny
if motive == vanity: deny
if reading.implies dual_root: deny
else: allow partial open of Gen narrative
```

| `LetterGate_Bet` | Bet is access policy + blessing surface (1:10) |

| `OrderSplit_CreateVsFinish` | Create-order ≠ finish-order (1:15) |

