# Pass 5 — Creation vocabulary + person bindings

**Date:** 2026-07-23 · **Confidence:** observed; sample-based

## Observed

- Sections that mix creation language (*tohu*, *yehi or*, Ma’aseh Bereshit, *bereshit bara*…) with **זה + person**: on the order of **~18** hard hits in scan (not huge, but real).
- **BR 2:3** remains the densest multi-person creation registration.
- Elsewhere: Adam ↔ “very good” / dough of world; Noah ↔ flood righteousness; Abraham still bound to righteousness/fear/light-adjacent texts; Moses occasionally creation-adjacent wisdom.

## Hypothesis

Creation front **installs** several person-types in compressed form (2:3); later BR **reuses types** more than it re-cites that table. Creation language remains a **privileged attractor** for person binding, not the only one.
