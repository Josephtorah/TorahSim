## 4. What matches well (takeaways)

### A. Header pair is the backbone (**strong**)

```text
G1-L:  be-reishit bara Elohim
P22:   qanani reishit darko | qedem mif'alav
```

Same **reishit** token family.  
Gen = **use at create**. Prov = **define + prior-to-works**.  
This is the cleanest “resolve” edge in the alignment.

### B. Water / deep / earth stage cluster (**strong–partial**)

Prov spends **half the block** (24–29) on deeps, springs, heavens, sea bound, earth foundations.  
Gen 1:1–2 puts **earth + tehom + waters** on stage immediately.

Reading:

```text
Prov: "I existed when those were not / when He set them"
Gen:  "now those domains are created / present in chaos-then-light"
```

Same **stage vocabulary**, opposite **tense** (prior vs runtime).

### C. Boundary ops rhyme (**partial**)

- Gen 1:4: **divide** light | dark  
- Prov 8:29: **statute** so waters do not pass; foundations of earth  

Not the same verb, same **job class**: set hard limits on domains.

### D. Deliberate non-matches (important)

| Missing on Prov side | Missing on Gen 1:1–5 side |
|----------------------|---------------------------|
| **Light** (*or*) | **amon** role |
| *tov* evaluation | day-by-day delight |
| day/night naming | sons of man |

So Prov 8:22–31 is **not** a verse-by-verse clone of day one.  
It is a **prior companion + reishit + pre-structure of earth/water/sky** module.  
**Light** is a **different bus** (Gen 1:3–5; later Job/Prov light ports).

### E. BR’s two pins make sense as stage labels

| BR cite | Stage in this table |
|---------|---------------------|
| Prov 8:22 | **S0** header (*reishit*) |
| Prov 8:30 | **S10** companion role (*amon*) |
| Land Gen 1:1 | **S0 + S1/S2** create @ reishit + domains |

BR is not randomly quoting; it highlights **header** and **role** of the prior module, then lands on the **runtime line** that uses the header word.
