## 2. Petihah multi-cite protocol (ch.1–3 scan)

**Source:** `../SCAN_BR_petihah_shared_refs_2026-07-25.md`  
**Scale tested:** 23 multi-cite clusters · 94 distinct verses · BR ch.1–3  

### What failed

- Exact same word(s) in **every** cited verse of a cluster → almost always empty  
- One global passphrase for all openings → **no**

### What works — `PETIHAH_LINK_V1`

```text
OPEN  →  K1 HINGE ROOT (poly/rare; most proof-verses share family)
      →  K3 SUB-HUBS (optional; long units)
LAND  →  K2 BRIDGE (often different root into Gen)
```

| Example | K1 | K2 |
|---------|----|----|
| BR 1:1 *amon* | א־מ־ן / *ʼ-m-n* (tutor/foster/great/craft) | ראשית / *reishit* → Gen 1:1 |
| BR 1:4 inventory | ראשית + prior-time lattice | Gen 1:1 *Bereshit* |
| BR 1:5 | א־ל־ם mute ↔ sheaves | speech gate / Ma’aseh Bereshit |
| BR 1:7 | אמת + עולם (true dual stem) | ראש דברך → first word |
| BR 1:6 | chained: hide → light → fabric | Nakh explains Gen headers |
| BR 1:14 | method school (את/גם · אך/רק) | not a shared content root |

**Ambient** שמים / ארץ / מים = Gen 1 environment, not the hinge key.

**Label:** protocol on ch.1–3 **tested**; corpus-wide **hypothesis**.

## 4. Bridge operators (deep dives)

### 4.1 Prov 4:18 — light-path (reserve port)

וְאֹרַח צַדִּיקִים כְּאוֹר נֹגַהּ / *ve-oraḥ tzaddikim ke-or nogah* /  
“path of the righteous is like radiant light…”

- **4** BR sections: 1:6, 11:2, 12:6, 42:3  
- Job: proof that primordial light is **reserved for the righteous** (future / path to full day)  
- Same function, different sockets (creation open, Shabbat light, Gen 1:4 “good,” *vayehi* debate)  
- Doc: `BRIDGE_Prov_4_18_light_path_2026-07-26.md`

### 4.2 Job 38:15 — withhold light (hide port) · twin

וְיִמָּנַע מֵרְשָׁעִים אוֹרָם / *ve-yimana me-reshaim oram* /  
“their light is withheld from the wicked…”

- **2** BR sections only: **11:2** and **12:6**  
- **Always** co-present with Prov 4:18 in this dump  
- Job is the **stricter twin**: hide/withhold side of **גנז** / *ganaz* / “stored” light  
- Prov can appear **without** Job (1:6, 42:3); Job does **not** appear without Prov here  
- Doc: `BRIDGE_Job_38_15_withhold_light_2026-07-26.md`

### Twin package (tested on these loci)

```text
store_primordial_light():
  HIDE   ← Job 38:15   (from wicked)
  RESERVE ← Prov 4:18  (for righteous path / future day)
  optional: Gen 1:4 ki tov + Isa 3:10 (good = righteous)
  optional: Prov 13:9 (light of righteous rejoices)
```

**Limit:** This package is **BR/Oral manual** (Ketuvim proofs).  
In Written Torah, light+wicked and light+righteous co-occurrence = **0**.  
Torah-absolute analogue for split light: **Exod 10:21–23** (Egypt dark / Israel light). See method note.
