## Findings (none seat: no unit touched)

1. **THE PARSER READ `pk` AS `k`.** The daemon census's kind-condition regex had no word boundary, so
   the Passover daemon's `pk == 'bought_slave'` was parsed as a watched kind — and the gate FIRED on
   it three ways (unregistered kind, declaration ≠ parse, watched-never-fired). The regex now requires
   a non-identifier character before `k`; the five fire-probes still 5/5. A gate that fires on its
   own parser's fault is doing its job; the fix is one lookbehind.
2. **THE SCENE MUST RUN AFTER THE ENGINE'S CONSTANTS.** cold_run_moadim binds OM / PIL / SV after its
   functions; a scene placed before them raised NameError through the incense_shekel runner's import.
   Moved below the bindings, above TESTS — the rule for W3 onward: the scene sits immediately above
   the test table.
3. **THE COLD-IMPORT RUNNER.** cold_run_pesach runs its grading under `if __name__ == '__main__'` because
   the offerings dispatcher imports it; its daemon is module-level (the parser needs the def), its
   scene runs under main, and the CASES row's lambda binds SCENE at run time.
