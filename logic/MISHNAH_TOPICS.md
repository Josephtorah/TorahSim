# THE MISHNAH — the topic map, in its own order

**Date:** 2026-08-23 · **Method:** the opening of every chapter (all 525) read
from the local Hebrew corpus (`Data/mishnah_*_he.json`), canonical order,
counts verified: **63 tractates · 525 chapters · ~4,192 teaching units.**
**Use:** door 2 of the join — given a law span, walk this list to the
tractates and chapters that implement it. In software terms: the Torah is the source;
the Mishnah is the expected-output table of the system that ran on it —
fixtures by module, never citing the source line. Step 5 claims source,
Step 9 test suite.
**Naming:** Mishnah, [English name]; Hebrew always glossed.
**Maintained in the workshop** (owner 2026-08-23): for this file the
workshop holds the living copy and the keep-it-current duty — updated in
place there as tractates actually get read, relayed here and mirrored on
each update (the reverse of the canon-home flow, by the owner's order).
Model layer, not a ledger.
**Not** binding religious law.

The code opens with how you speak to God (Blessings) and closes on a
hairline of what-is-part-of-what (Stems). Topic order, never verse order.
