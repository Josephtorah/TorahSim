# Part 1 — How to read this (start here)

## The big idea in one picture

Imagine each verse is a **sentence the synagogue already marked with pauses and groupings** (the **ta’amim** / cantillation marks).  

Those marks build a **tree**: small groups of words hang under larger groups, like branches.

```text
        WHOLE VERSE
       /            \
   LEFT half      RIGHT half     ← often a big mid-verse pause (אתנחתא / etnachta)
    /    \          /    \
  ...   ...      ...    ...
 [0][1][2]      [3][4]…         ← LEAVES = single words (we number them)
```

**A leaf** = one Hebrew word (sometimes with a little prefix glued on, like “and-” or “the-”).

**Logic** = what we are allowed to say the verse is *doing*, **only** if some leaf or group of leaves supports it.

> **Rule of honesty:**  
> If a detail is not sitting on a leaf (or a clear tree-group of leaves), we did **not** get it from the tree.  
> Cutting the verse only into “left half / right half” and stopping is **not enough** — you lose who does what to whom.

## Four questions we ask every verse

1. **What are the words?** (list every leaf with English)  
2. **How does the tree group them?** (which words cling together?)  
3. **What job does each word do?** (who / action / thing acted on / name / “and it was so” …)  
4. **What is true in the world after this verse?** (running story)

## Tiny dictionary (no coding needed)

| Plain name | Hebrew example | What it does |
|------------|----------------|--------------|
| **Who** | אֱלֹהִים / *Elohim* / “God” | The one acting |
| **Action word** | בָּרָא / *bara* / “created” | What is done |
| **Object marker** | אֵת / *et* | Points at the thing the action hits (like a finger: “this object”) |
| **Thing / domain** | הַשָּׁמַיִם / *ha-shamayim* / “the heavens” | What exists or is affected |
| **Speech** | וַיֹּאמֶר / *va-yomer* / “and he said” | A command is spoken |
| **Wish-form** | יְהִי / *yehi* / “let there be” | “I want this to exist” |
| **Result-form** | וַיְהִי / *va-yehi* / “and there was” | It actually happened |
| **Divide** | הִבְדִּיל / *hivdil* / “divided” | Split A from B |
| **Call / name** | קָרָא / *qara* / “called” | Give a public name |
| **See / check** | רָאָה / *ra’ah* / “saw” | Inspect |
| **Good** | טוֹב / *tov* / “good” | Passes the check |
| **Bless** | בֵּרַךְ / *berakh* / “blessed” | Put a lasting package of commands on someone |
| **And it was so** | וַיְהִי כֵן / *va-yehi khen* | “Done — command fulfilled” |
| **Day close** | עֶרֶב … בֹקֶר … יוֹם | Evening then morning stamps a day number |

## Running picture of the world

We keep a simple mental checklist that fills in as we go:

```text
□ Who is acting?
□ What big places exist? (heavens, earth, waters…)
□ Is there light? Separated from dark?
□ Names: Day / Night / Earth / Seas / Heavens…?
□ Living things? Blessings? Food rules?
□ Which days have closed? (1…7)
□ Is work finished? Did God cease? Is day 7 holy?
```

## Verse 1:1 — “In the beginning God created the heavens and the earth”

### Plain English of the verse

At the start, God created two big domains: the heavens and the earth.

### Full tree (every leaf numbered)

```text
WHOLE VERSE (7 words)
├── LEFT (3 words) — “when + create + who”
│   ├── [0] בְּרֵאשִׁית
│   └── group: create + who
│       ├── [1] בָּרָא
│       └── [2] אֱלֹהִים     ← big pause (etnachta) sits here
└── RIGHT (4 words) — “two marked objects”
    ├── group: object #1
    │   ├── [3] אֵת
    │   └── [4] הַשָּׁמַיִם
    └── group: object #2
        ├── [5] וְאֵת
        └── [6] הָאָרֶץ
```

### Every leaf (must all be used)

| # | Hebrew | Sounds like | English | Job in plain words |
|---|--------|-------------|---------|-------------------|
| 0 | בְּרֵאשִׁית | *be-reshit* | “In beginning” | **When** this happens |
| 1 | בָּרָא | *bara* | “created” | **Action** |
| 2 | אֱלֹהִים | *Elohim* | “God” | **Who** (pause lands on the Who) |
| 3 | אֵת | *et* | (object finger) | Marks next word as **thing acted on** |
| 4 | הַשָּׁמַיִם | *ha-shamayim* | “the heavens” | **Object 1** |
| 5 | וְאֵת | *ve-et* | “and *et*” | Marks **second** object in the list |
| 6 | הָאָרֶץ | *ha-arets* | “the earth” | **Object 2** |

### What the tree teaches (logic)

Look how words **cling**:

- **[1]+[2]** stick together → the action “created” belongs with “God,” not with “beginning.”  
- **[0]** sits beside that pair → “beginning” is the **time frame**, not something God creates in this list.  
- **[3]+[4]** and **[5]+[6]** are twin pairs → two objects, each with its own *et* finger.

**Logic we may state (because every piece has a leaf):**

1. **When:** beginning ([0])  
2. **Who:** God ([2])  
3. **Does:** create ([1])  
4. **Creates both:** heavens ([4]) **and** earth ([6]), each pointed to by *et* ([3], [5])

**Kitchen analogy:**  
Recipe title: “At the start, Chef creates *both* the upper shelf *and* the lower shelf.”  
The words “both…and…” are not decoration — they are the two *et* fingers.

### World after 1:1

```text
Who: God
Places: heavens ✓  earth ✓
Light: not yet
Names: none yet
Days closed: none
```

## Verse 1:2 — raw earth, dark deep, spirit over waters

### Plain English

The earth was waste and empty; darkness was on the face of the deep; and the spirit of God was hovering on the face of the waters.

### Tree in plain English (14 leaves)

The big pause (etnachta) cuts the verse into:

**LEFT (through the deep):** earth’s condition + darkness on the deep  
**RIGHT:** spirit of God hovering on the waters  

Inside LEFT there are **two clusters**:

1. Earth **was** waste-and-void  
2. Darkness **on the face of** the deep  

Inside RIGHT:

3. Spirit-of-God **hovering on the face of** the waters  

### Every leaf

| # | he / translit / en | Job |
|---|---------------------|-----|
| 0 | וְהָאָרֶץ / *ve-ha-arets* / “and the earth” | **Subject** of the “was…” line |
| 1 | הָיְתָה / *hayetah* / “was” | **Was** (state verb) |
| 2 | תֹהוּ / *tohu* / “formless waste” | Condition A |
| 3 | וָבֹהוּ / *va-vohu* / “and void” | Condition B (pairs with A) |
| 4 | וְחֹשֶׁךְ / *ve-choshekh* / “and darkness” | Dark layer |
| 5 | עַל / *al* / “on” | Location word |
| 6 | פְּנֵי / *penei* / “face of” | “Surface of…” |
| 7 | תְהוֹם / *tehom* / “deep” | What darkness sits on (**pause here**) |
| 8 | וְרוּחַ / *ve-ruach* / “and spirit” | Spirit |
| 9 | אֱלֹהִים / *Elohim* / “God” | Whose spirit |
| 10 | מְרַחֶפֶת / *merachefet* / “hovering” | Action of spirit |
| 11 | עַל / *al* / “on” | Location word (again) |
| 12 | פְּנֵי / *penei* / “face of” | Surface (again) |
| 13 | הַמָּיִם / *ha-mayim* / “the waters” | What spirit hovers over |

### Logic from the groups (not from a blur)

| Group (leaves) | Plain logic |
|----------------|-------------|
| [0]–[3] | Earth **was** {waste, void} |
| [4]–[7] | Darkness is **on the face of the deep** (not “dark exists somewhere vague”) |
| [8]–[13] | Spirit **of God** is **hovering on the face of the waters** |

**Notice the rhyme the tree keeps:**  
“on the face of the deep” ([5][6][7]) mirrors “on the face of the waters” ([11][12][13]).  
That parallel is **leaf structure**, not our imagination.

### World after 1:2

```text
Earth: raw (waste + void)
Dark: on the deep’s face
Waters: present; God’s spirit over their face
Light: still off
```

## Verse 1:3 — “Let there be light” and there was light

### Plain English

God said: “Let light be.” And light was.

### Full tree (6 leaves) — easiest teaching verse

```text
WHOLE
├── LEFT (command side) — pause on “light”
│   ├── [0] וַיֹּאמֶר  “and he said”
│   ├── [1] אֱלֹהִים  “God”
│   ├── [2] יְהִי      “let there be”
│   └── [3] אוֹר      “light”   ← mid-verse pause
└── RIGHT (result side)
    ├── [4] וַיְהִי    “and there was”
    └── [5] אוֹר      “light”   ← end of verse
```

### Every leaf’s job

| # | he / translit / en | Job |
|---|---------------------|-----|
| 0 | וַיֹּאמֶר / *va-yomer* / “said” | **Speech action** |
| 1 | אֱלֹהִים / *Elohim* / “God” | **Who** speaks |
| 2 | יְהִי / *yehi* / “let there be” | **Wish / command mood** |
| 3 | אוֹר / *or* / “light” | **What** is wished (pause sits on this) |
| 4 | וַיְהִי / *va-yehi* / “and there was” | **Result** verb |
| 5 | אוֹר / *or* / “light” | **What** actually appears |

### Logic (forced by leaves)

1. **Who speaks:** God ([1]) with “said” ([0]).  
2. **Command content:** “let there be” ([2]) + **light** ([3]).  
3. **Fulfillment:** “and there was” ([4]) + **light again** ([5]).

**Why two “light” leaves matter:**  
The same thing is named once in the **wish** and once in the **result**.  
The tree is teaching a **match**: what was ordered is what arrived.

**Spoken logic:**

> God **says** a wish for light → the world **answers** with light.

### World after 1:3

```text
Light: ON
```

## Verse 1:4 — check the light; split light from dark

### Plain English

God saw the light, that it was good; and God divided between the light and the darkness.

### Tree (12 leaves) — two separate actions

```text
WHOLE
├── LEFT — “see + good” (pause on “good”)
│   [0] saw  [1] God  [2] et  [3] the-light  [4] that  [5] good
└── RIGHT — “divide + between pair”
    [6] divided  [7] God  [8] between  [9] the-light  [10] and-between  [11] the-dark
```

### Leaf jobs (short)

| # | he / translit / en | Job |
|---|---------------------|-----|
| 0 | וַיַּרְא / *va-yar* / “saw” | Inspect action |
| 1 | אֱלֹהִים / *Elohim* / “God” | Who sees |
| 2 | אֶת / *et* | Object finger → light |
| 3 | הָאוֹר / *ha-or* / “the light” | What is seen |
| 4 | כִּי / *ki* / “that” | Opens the grade |
| 5 | טוֹב / *tov* / “good” | Grade (**pause**) |
| 6 | וַיַּבְדֵּל / *va-yavdel* / “divided” | **New** action |
| 7 | אֱלֹהִים / *Elohim* / “God” | Who divides (**God said again**) |
| 8 | בֵּין / *bein* / “between” | First “between” |
| 9 | הָאוֹר / *ha-or* / “the light” | Pole A |
| 10 | וּבֵין / *u-vein* / “and between” | Second “between” |
| 11 | הַחֹשֶׁךְ / *ha-choshekh* / “the darkness” | Pole B |

### Logic from the tree

**Left half = quality check**

> God sees the light **that it is good**.

**Right half = structure move** (new verb, God named again)

> God divides **between light and between dark**.

**Analogy:** First you taste the soup (check). Then you pour oil and vinegar into separate cups (divide). Two jobs, two verb-groups on the tree.

### World after 1:4

```text
Light: ON and checked GOOD
Light | Dark: SEPARATED as a pair
```

## Verse 1:5 — name Day and Night; close day one

### Plain English

God called the light “Day,” and the darkness He called “Night.” Evening and morning: day one.

### Tree (13 leaves) — naming left, clock right

```text
WHOLE
├── LEFT (naming) — pause on “Night”
│   First naming:  [0] called [1] God [2] to-the-light [3] Day
│   Second naming: [4] and-to-the-dark [5] called [6] Night
└── RIGHT (clock)
    [7] and-was [8] evening [9] and-was [10] morning
    [11] day [12] one
```

### Leaf jobs — special care (easy to miss)

| # | he / translit / en | Job |
|---|---------------------|-----|
| 0 | וַיִּקְרָא / *va-yiqra* / “called” | **First** naming verb |
| 1 | אֱלֹהִים / *Elohim* / “God” | Who names |
| 2 | לָאוֹר / *la-or* / “to the light” | Thing getting a name |
| 3 | יוֹם / *yom* / “Day” | **Name-label** for light |
| 4 | וְלַחֹשֶׁךְ / *ve-la-choshekh* / “and to the dark” | Second thing named |
| 5 | קָרָא / *qara* / “called” | **Second** naming verb (own leaf!) |
| 6 | לָיְלָה / *lailah* / “Night” | **Name-label** for dark (**pause**) |
| 7 | וַיְהִי / *va-yehi* / “and was” | Clock: “there was…” |
| 8 | עֶרֶב / *erev* / “evening” | Clock part 1 |
| 9 | וַיְהִי / *va-yehi* / “and was” | Clock again |
| 10 | בֹקֶר / *voqer* / “morning” | Clock part 2 |
| 11 | יוֹם / *yom* / “day” | Day **unit** (not the same job as [3]!) |
| 12 | אֶחָד / *echad* / “one” | Day **number** |

**Two different “day” leaves:**

- **[3] יוֹם** = the **name** of the light  
- **[11] יוֹם** = the **day-count word** in “day one”

Same spelling, **two jobs**. The tree keeps both; a sloppy summary merges them and loses detail.

### Logic

1. Name light → Day ([0]–[3])  
2. Name dark → Night ([4]–[6]) with its **own** “called”  
3. Evening happens, morning happens ([7]–[10])  
4. Stamp: day one ([11]–[12])

### World after 1:5 (end of Day 1)

```text
Light ON, good, separated from dark
Public names: light→Day, dark→Night
Day cycle: evening then morning
Days closed: 1
```

### 1:7 — Make the firmament; divide under/above; “and it was so”

**Tree shape (17 leaves)**

```text
Big left: MAKE firmament + DIVIDE waters under it from waters above it
Big right: “and it was so”
```

**Core leaf jobs (all words participate; listed by job clusters)**

| Cluster | Leaves (he / en) | Logic |
|---------|------------------|-------|
| Make frame | [0] וַיַּעַשׂ / “made” · [1] אֱלֹהִים / “God” · [2] אֶת / *et* · [3] הָרָקִיעַ / “the firmament” | God **makes** the firmament (object-marked) |

| Fulfill | last: וַיְהִי כֵן / *va-yehi khen* / “and it was so” | **Done** — matches the speech |

**Under / above detail (why leaves matter):**  
The tree does not only say “split water.” It adds **אֲשֶׁר מִתַּחַת** / *asher mi-tachat* / “that is under” and **אֲשֶׁר מֵעַל** / *asher me‘al* / “that is above.”  
Those are real words → real logic: two **locations**, not a vague splash.

**World after 1:7**

```text
Firmament: MADE
Waters: below-firmament | above-firmament
Command of 1:6: fulfilled (“and it was so”)
```

### 1:11–12 — Plants by kind (speech, then earth produces, then good)

**1:11 key leaves:** God said → earth sprout vegetation → grass seeding seed → fruit tree making fruit **לְמִינוֹ** / *le-mino* / “by its kind” → and it was so.

**1:12 key leaves:** earth **brought forth** those plants by kind → God saw good.

**Logic:**  
- **Speech** (11) sets the plant program **with a type rule** (“by kind”).  
- **Execution** (12) is the earth actually producing.  
- **Check** (12): good.

**“By kind” is a leaf phrase** — without it, you only get “plants,” not “plants that stay true to type.”

## DAY 5 — Sea life, birds, first blessing (1:20–23)

### 1:20 — Speech: waters swarm; birds fly

**Tree:** left = let waters swarm with living swarms; right = birds fly over the earth across the firmament face.

**Logic from both arms:** two biomes at once — **water life** and **sky/earth-face flight**.

---

### 1:21 — Create great sea creatures, living things by kind, winged birds; good

Key leaves include **בָּרָא** / *bara* / “created” (strong create verb), **תַּנִּינִים** / *tanninim* / great sea creatures, **לְמִינֵהֶם** / *le-minehem* / “by their kinds,” **עוֹף כָּנָף** / *of kanaf* / winged bird, then **good**.

**Logic:** Actual creation of animal life + **kind** constraint + quality check.

---

### 1:22 — Blessing package (listen to every command word)

**Hebrew sense:** God blessed them, saying: be fruitful; multiply; fill the waters in the seas; and let the bird multiply on the earth.

**Tree:** left = bless them, saying…; right = the command list.

| he / translit / en | Job in the package |
|--------------------|--------------------|
| וַיְבָרֶךְ / *va-yevarekh* / “blessed” | Install blessing |
| פְּרוּ / *peru* / “be fruitful” | Command 1 |
| רְבוּ / *revu* / “multiply” | Command 2 |
| מִלְאוּ אֶת הַמַּיִם בַּיַּמִּים / fill the waters in the seas | Command 3 (sea domain) |
| וְהָעוֹף יִרֶב בָּאָרֶץ / bird multiply on the earth | Command 4 (land domain for birds) |

**Logic:** A blessing here is not a vague “be well.” It is a **stored list of life-commands** with **domains** (seas vs land).

## DAY 6 — Land animals, human, rule, food (1:24–31)

### 1:24–25 — Land animals by kind; good

Speech: earth bring living things — cattle, crawlers, wild land animals — by kind; and it was so.  
Then God **made** them by kind; saw good.

**Logic:** Same speech→make→good pattern as plants, now for land animals; **by kind** again.

### 1:26 — Speech: human in image + rule job

**Tree:** left = let us make human in our image/likeness; right = and they shall rule fish, birds, cattle, all earth, crawlers.

| he / translit / en | Job |
|--------------------|-----|
| נַעֲשֶׂה אָדָם / *na‘aseh adam* / “let us make human” | Intent to make |
| בְּצַלְמֵנוּ כִּדְמוּתֵנוּ / *be-tsalmenu ki-dmutenu* / “in our image, like our likeness” | **How** human is specified |
| וְיִרְדּוּ / *ve-yirdu* / “and they shall rule” | **Job description** before the create finishes |

**Logic:** Human is not only “a creature.” The tree’s right arm lists **rule over** the life already installed.

---

### 1:27 — Create human in image; male and female

**Tree:** left = created the human in His image…; right = male and female He created them.

**Key leaves:** בָּרָא / created · אָדָם / human · בְּצַלְמוֹ / in His image · בְּצֶלֶם אֱלֹהִים / in image of God · זָכָר וּנְקֵבָה / male and female.

**Logic:** Creation in image + sexual pair as created fact (own right branch).

---

### 1:28 — Human blessing (compare 1:22)

Blessing + speech: be fruitful, multiply, **fill the earth and subdue it**, and **rule** sea fish, sky birds, land living things.

| Extra words vs 1:22 | Meaning |
|---------------------|---------|
| מִלְאוּ אֶת הָאָרֶץ / fill the **earth** | Domain is land, not only seas |
| וְכִבְשׁוּהָ / *ve-khivshuha* / “and subdue it” | Extra command |
| וּרְדוּ / *u-redu* / “and rule” | Rule the animal classes |

**Logic:** Same family as day-5 blessing, **more fields** for humans — tree lists them as separate leaves/phrases.

---

### 1:29–30 — Food policy

**1:29:** God said: look, I gave you every seed-bearing plant… and every tree with seed-bearing fruit… **for you it shall be food**.

**1:30:** And to all land life, birds, crawlers… **all green herb for food**; and it was so.

**Logic from leaves:** two food grants —

- Humans ← seed plants + fruit trees  
- Animals ← green herb  

Without the “for food” leaves, you only have “plants exist,” not **permission to eat**.

---

### 1:31 — All very good; day six

**Leaves:** God saw **all** that He made, and behold **very good**; evening, morning, **the sixth day**.

**Logic:** Highest check — not one object, the **whole system**. Day 6 closes.

## DAY 7 — Finish, cease, make the day holy (2:1–3)

### Story

No new animals. The build is sealed: finished → stopped → day blessed and sanctified.

---

### 2:1 — Finished: heavens, earth, and all their host

**Leaves (5)**

| # | he / translit / en | Job |
|---|---------------------|-----|
| 0 | וַיְכֻלּוּ / *va-yekhullu* / “were finished” | Finish verb |
| 1 | הַשָּׁמַיִם / “the heavens” | Domain 1 |
| 2 | וְהָאָרֶץ / “and the earth” | Domain 2 |
| 3 | וְכָל / “and all” | Totalizer |
| 4 | צְבָאָם / *tseva’am* / “their host” | Everything that belongs with them |

**Logic:** Completion statement for the whole install + host.

---

### 2:2 — Finished work on day seven; ceased on day seven

**Tree:** left = God finished on the seventh day His work which He made; right = He ceased on the seventh day from all His work which He made.

**Key leaves**

| he / translit / en | Job |
|--------------------|-----|
| וַיְכַל / *va-yekhal* / “finished” | Complete the work |
| בַּיּוֹם הַשְּׁבִיעִי / “on the seventh day” | When (appears on **both** halves) |
| מְלַאכְתּוֹ / *melakhto* / “His work” | What is finished / left |
| וַיִּשְׁבֹּת / *va-yishbot* / “and He ceased” | **Stop** action |
| מִכָּל מְלַאכְתּוֹ / “from all His work” | Scope of stopping |

**Logic:** Two different verbs — **finish** and **cease** — both timed to day seven.  
Ceasing is not the same leaf as finishing.

---

### 2:3 — Bless and sanctify day seven, **because** He ceased

**Tree:** left = blessed the seventh day and sanctified it; right = **because** on it He ceased from all His work which God created to make.

**Key leaves**

| he / translit / en | Job |
|--------------------|-----|
| וַיְבָרֶךְ / “blessed” | Bless the **day** |
| וַיְקַדֵּשׁ / *va-yeqaddesh* / “sanctified” | Make the day **holy** |
| כִּי / *ki* / “because” | Reason marker |
| בּוֹ שָׁבַת / *bo shavat* / “on it He ceased” | The reason |

**Logic:** Day 7 is special **because of the cease**, not because a new creature was made.  
The tree’s right arm is the **reason clause** hanging off the bless/sanctify left arm.

**World after Day 7 (end of boot)**

Day 7: BLESSED + HOLY

# Part 5 — The pattern you can hear by now

Most create days sound like this when you listen with the tree:

1. **God said** (speech leaves)  
2. **Something is** (make/create/result leaves)  
3. Sometimes **name**, **divide**, **bless**, or **give food** (those are extra leaf groups)  
4. Sometimes **saw that it was good**  
5. **Evening and morning — day N**

Day 7 breaks the pattern on purpose:

1. **Finished**  
2. **Ceased**  
3. **Blessed + sanctified the day because of ceasing**

# How to use this if you feel lost

1. Pick **one verse** (start with **1:3** — only six words).  
2. Read the English.  
3. Look at the tree picture: which words sit left of the pause, which right?  
4. Read the leaf table: every word has a job.  
5. Read “logic”: only those jobs.  
6. Read “world after”: what changed?

Then do **1:1** (dual objects), then **1:5** (two names + clock), then skim days 2–7 with the storyboard.

The create week is a careful sequence of **speech, make, name, divide, bless, feed, check, and rest** — and we only say each piece because **the tree’s leaves put that word in that job**.
