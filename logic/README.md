# logic/ — the canonical derivation layer

This directory is the plate the prints are struck from. Until 2026-08-20
it lived in the private workshop and TorahSim carried only its renderings
— the runnable units in `units/` and the review pages in `scroll/units/`.
On that date the whole capability crossed, one way, as everything else
has crossed: finished, redacted at the border, and provable on arrival.

## What is canonical here

- **`units/*.yaml`** — the 97 frozen unit derivations, Pre-Code. Each
  step carries its verse, its Hebrew with transliteration and gloss, its
  operator list with citations and confidence, and its tree halves. The
  Python renderings in `../units/` and the review pages in
  `../scroll/units/` are both generated from these files by the press
  (`../press/`); the sixth gate in `../tools/check.py` reprints the whole
  pool on every run and diffs it against the shipped copies.
- **`SCHEMA.yaml`** — what a unit file must contain.
- **`glosses/word_gloss_overrides.yaml`** — owner gloss rulings. The
  standing law travels with it: gloss fixes are made here, at the display
  layer, never inside a frozen YAML.
- **`taamim_rules/`** — the versioned cantillation-parse rule sets
  (`CURRENT` names the one in force), read by the tree parser.
- **`role_rules/`, `lexicon/`, `templates/`** — the rule and lexicon
  inputs the database build reads.
- **`corpus/`** — the world layer: `entity_registry.yaml` and
  `settlement_links.yaml` (authored config, uncertainty marked), and
  `CORPUS_TRUTH.py` (generated by `../press/corpus_world.py`; running it
  refolds all 97 units into one world and asserts the identical state
  hash).

## What is a preserved record here

`docs/` (the workshop's method documents and tutorials), `oral_triage/`
(the TIR citation ledgers behind every `cites:` field), `oral_audit/`
(the chain-attestation audit records the oral-audit pages render), the
`taamim_rules/` version notes, and `FETCHLOG.md` (the append-only Tier-A
fetch log) are received records: shipped as written, reported by the
gloss lint but never gated, never retouched. See method law 8.

## The border redaction

One documented redaction was applied at copy time, continuing the
convention set when the review pages crossed. Every occurrence of the
workshop's name and its private filenames was neutralized to the names
this repository actually uses:

| in the workshop | here |
|---|---|
| the workshop's live database | `derivation.sqlite` |
| its pinned gloss snapshot | `source-snapshot.sqlite` |
| its pinned debut-census snapshot | `debut-snapshot.sqlite` |
| its working-notes folder | `provenance/` |
| its interim coordinator, by name | "the interim coordinator" |

Thirty-seven references were rewritten across the crossing; a sweep for
the old names over `logic/` and `press/` returns zero. Nothing else was
changed: operator text, citations, confidence grades, and Hebrew are
byte-for-byte as frozen. The proof that the redaction cost nothing is
mechanical — the reprinted pool matches the shipped pool, the reprinted
scroll bundles match the shipped bundles 189 files for 189, and the world
fold lands on the workshop's own state hash.

## The databases

The press reads `../data/derivation.sqlite` (~3.2 GB), rebuilt from
`../shelf/sources/` by `../press/build_db.py` and the indexers — see
`../docs/SOURCES.md` for the chain. The two pinned snapshots
(`source-snapshot.sqlite`, `debut-snapshot.sqlite`) are frozen provenance
artifacts cited by the derivations: not rebuildable, kept out of git for
size, back them up. All four database files are uncommitted, like
`../shelf/`.
